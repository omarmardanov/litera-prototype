# Litera.studio — редизайн · статус прототипа

Обновлено: 2026-06-20

## Стек
- Статичная вёрстка, HTML + Tailwind (CDN, конфиг в `<head>`).
- Шрифт: Raptor V2 (лицензия у заказчика) первым в стеке; видимый fallback — Manrope. Файлы Raptor класть в `prototype/assets/`, раскомментировать `@font-face`.
- Цветовая система: фирменная палитра, цвет на направление (Полиграфия — синий, Упаковка — magenta, Брендинг — лайм, Мерч — зелёный, Реклама — жёлтый). На белом фоне лайм/жёлтый затемнены (#9bbf00 / #d4b300) для контраста.

## Готово
- `category.html` — эталонная страница категории (Полиграфия, синий акцент). Все блоки:
  шапка с направлениями в меню (короткие лейблы + выпадашки) → hero «веером» карточек продукта (1:1 с концептом) → выгоды (monoline-графика) → виды → материалы → 3 ценовых блока (пакеты/таблица/расчёт) → процесс → кейсы → доверие → FAQ → CTA-форма → перелинковка → подвал.
- `portfolio.html` — страница портфолио (bento-сетка, фильтр по направлениям). **Запаркована**, вернёмся позже.
- `../Предложение по структуре сайта.md` — документ для заказчика (структура каталога, 3 варианта, цветовая система, решения по наполнению).
- `index.html` — **главная (зонтик над 5 направлениями)**. Пока: шапка + первый экран. Внизу панель «Гид по прототипу» — пульт сравнения вариантов + пояснения для заказчика (служебный, в финале вырезать).

## Главная — варианты на согласовании (index.html)
Первый экран, 3 варианта (тумблер «Первый экран»):
- **A · Цветошкала** — типографика + полноширинная полоса из 5 цветных колонок-направлений (фирменные цвета как навигация).
- **B · Сплит + фото** — текст слева, фото-flatlay справа.
- **C · Полноэкранный цвет** — язык в духе G.F Smith: полноэкранный фирменный цвет, гигантский Raptor, заголовок морфится под направление, нижние свотчи перекрашивают экран + шапку.

Каталог — только для варианта C (тумблер «Каталог»):
- **1 · Выпадашка (флуд)** — привычное мегаменю, но панель заливается цветом направления. *Пока сырой.*
- **2 · Во весь экран** — полноэкранный индекс-тейковер: 5 направлений крупно слева, категории справа; шапка сворачивается до минимума (лого + «Меню»), вторичные ссылки/контакты внутри оверлея.

Текущий фаворит (для заказчика): **C + каталог «Во весь экран»**, второй — **A (Цветошкала)**.
Глубина каталога и все ссылки сохранены во всех вариантах — меняется только подача.

## Онлайн-демо
- Живёт отдельным чистым репозиторием `~/litera-prototype` → `github.com/omarmardanov/litera-prototype`, GitHub Pages.
- Ссылка для заказчика: **https://omarmardanov.github.io/litera-prototype/**
- Обновление: правим `prototype/*` здесь → копируем в `~/litera-prototype` → commit + push (Pages пересобирается ~1 мин).
- В деплой кладём только `index/category/portfolio.html` + `assets/` (без STATUS.md, тяжёлых PNG и материалов заказчика). В деплой-копии `category.html` подставлены недостающие `card-*.jpg`.
