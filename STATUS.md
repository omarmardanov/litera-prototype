# Litera.studio — редизайн · статус прототипа

Обновлено: 2026-07-02

## Стек
- Статичная вёрстка, HTML + Tailwind (CDN, конфиг в `<head>`).
- Шрифт: Raptor V2 (лицензия у заказчика) первым в стеке; видимый fallback — Manrope. Файлы Raptor класть в `prototype/assets/`, раскомментировать `@font-face`.
- Цветовая система: фирменная палитра, цвет на направление (Полиграфия — синий, Упаковка — magenta, Брендинг — лайм, Мерч — зелёный, Реклама — жёлтый). На белом фоне лайм/жёлтый затемнены (#9bbf00 / #d4b300) для контраста.

## Готово
- `category.html` — эталонная страница категории (Полиграфия, синий акцент). Все блоки:
  шапка с направлениями в меню (короткие лейблы + выпадашки) → hero «веером» карточек продукта (1:1 с концептом) → выгоды (monoline-графика) → виды → материалы → 3 ценовых блока (пакеты/таблица/расчёт) → процесс → кейсы → доверие → FAQ → CTA-форма → перелинковка → подвал.
- `portfolio.html` — страница портфолио (bento-сетка, фильтр по направлениям). **Запаркована**, вернёмся позже.
- `../Предложение по структуре сайта.md` — документ для заказчика (структура каталога, 3 варианта, цветовая система, решения по наполнению).
- `index.html` — **главная (зонтик над 5 направлениями)**. Полная страница собрана (первый экран + все секции ниже, см. «Структура главной»). Внизу панель «Гид по прототипу» — пульт сравнения вариантов + пояснения для заказчика (служебный, в финале вырезать).

## Главная — 2 версии на согласовании (index.html)
Финализировали до 2 версий в тумблере «Первый экран»:
- **A · Цветошкала** — типографика по центру + полоса из 5 цветных колонок-направлений (фирменные цвета как навигация). Шкала приведена в контейнер шапки (`max-w-7xl`, края по логотипу/кнопке), высота 28vh, подписи 01–05 со знаком «Б».
- **C · Полноэкранный цвет** — язык в духе G.F Smith: полноэкранный фирменный цвет, гигантский Raptor, заголовок морфится под направление, автокарусель по направлениям. Зашитая комбинация: **индекс направлений справа** + **каталог во весь экран** (шапка свёрнута до лого + «Меню», вторичные ссылки/контакты в оверлее).

Фаворит для заказчика: **C**, второй — **A**. Глубина каталога и все ссылки сохранены в обеих версиях.

**В архиве** (код в `index.html`, из показа убран): hero B (Сплит+фото), hero D (Премиум светлый, бумага + серифный акцент Instrument Serif), hero E (Премиум тёмный); под-режимы каталога «Выпадашка»; переключатели направлений «Точки»/«Вкладки». Вернуть любой — добавить кнопку в гид + пункт в массив `variants`.

### Структура главной (скелет собран 2026-06-30)
Полная страница ниже первого экрана — общий body для обеих версий. Порядок блоков:
1. Hero (A/B) · 2. Бегущая строка · 3. **Манифест** (УТП «Полиграфическая клиника для бизнеса» — *лёгкий* клинический акцент, по решению заказчика) · 4. **Направления-витрина** (5 карточек + CTA) · 5. **Свой цикл/производство** (тёмный, стат-цифры) · 6. **Портфолио** (чипы-фильтр + bento) · 7. **Процесс** (5 шагов) · 8. **Доверие** (логотипы + отзывы) · 9. **Блог** (3 поста) · 10. **Лид-форма** (`#lead`: «менеджер-терапевт» на матовом стекле + чипы-направления, синтез референсов) · 11. **Футер** (гигантское градиентное «ЛИТЕРА», 4 колонки, контакты с копированием/маршрутом).

Дизайн-система сведена (2026-06-30, проход «ультимативно»): единая шапка секции (кикер с литера-маркой + дисплейный заголовок + текст-ссылка `.tlink` со стрелкой), «коробки» расхлопнуты в редакционные хэйрлайны (манифест, статы, цитаты, логострип), цвет — только в сигнатурных местах (шкала героя, карточки направлений, панель формы, засечка футера), нумерация — только в процессе. Футер: гигантское «ЛИТЕРА» тоном (не радужный градиент) + цветошкала-засечка.

**Контент взят с официального litera.studio** (2026-06-30): реальные названия направлений и услуг, проекты в портфолио (Любимая кружка, Ohana, FIRDAWS, ПРОМАКТИВ, Реилго), статьи блога с датами, клиенты в логострипе (ПРОМАКТИВ, Sequoiapay, Реилго, Модум-Транс, FIRDAWS, Complex Smile), слоган производства «Дизайним и печатаем на своём производстве».

На сайте **4 направления** (Полиграфия; Упаковка и этикетки; Логотип и фирменный стиль; Корпоративный брендинг и сувениры) — «Реклама/соцсети» и «Отраслевые» как направления отсутствуют (отрасли — фильтр в `/projects`). В прототипе сохранили 5-карточную сетку: 4 официальных + 5-я «Отраслевые решения» = честно сборки по отраслям. Развилка 4 vs 5 всё ещё открыта.

Добавлены блоки: **reels** (вертикальные видео-карусель на тёмном, как на сайте; стрелки навигации), **Litera Gifts** (саббренд literagifts.ru — сплит-панель, зелёный #00CC00 акцент, реальные цифры каталога), **отзывы каруселью** (реальные 2ГИС: 5,0 / 10 отзывов — Егор Дронов, Максим Пирожков, Nevada More, Городской житель; стрелки под отзывами справа от ссылок 2ГИС/Яндекс).

⚠️ Не подтверждено / плейсхолдеры: цифры блока производства («1000+/0» — маркетинг, уточнить; 2012 — из репо). Видео reels — постеры-плейсхолдеры: на сайте видео грузятся через JS, файлами не вытащить → брать у заказчика. Фото работ — тоже не вытащить (на сайте вшиты как `data:image`), есть только реальные названия проектов; настоящие фото — у заказчика. Аватары в отзывах — заглушки.

Контакты в топбаре и футере: клик по телефону/почте копирует (подсказка → «Скопировано»), адрес → «Построить маршрут» в Яндекс.Картах. Подсказки острые (класс `.cp`), консистентны с языком макета.
